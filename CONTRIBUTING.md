# Doprinos projektu

1. Otvori zasebnu granu.
2. Ne mijenjaj kanonski naziv **Radio Balkan** niti dodaj rebranding postavke browser ekstenzijama.
3. Pokreni `python scripts/check_versions.py`.
4. Pokreni testove/build za platformu koju mijenjaš.
5. Ne commitaj signing ključeve, tokene, `.env` ili build cache.
6. Pull request mora jasno navesti utjecaj na stabilnost, RAM/CPU, dozvole i kompatibilnost.
