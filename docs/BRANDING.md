# Radio Balkan branding

Kanonski naziv proizvoda je **Radio Balkan**.

## Vizualni identitet

- tamna baza: `#15110F`
- primarni znak: `#EB5323`
- browser UI accent: `#FFAD38`
- primarni tekst: gotovo bijela

Službeni vektorski znak je `assets/brand/logo.svg`, izveden iz istog vektorskog znaka koji koristi Android aplikacija. Browser paketi koriste službeni app icon iz `extensions/shared/`.

## Zaključani browser brand

Build browser ekstenzija mora pasti ako manifest više nije nazvan `Radio Balkan`, ako se uvede options/settings UI za promjenu brenda ili ako se vrati zabranjena nepotrebna dozvola. Korisnik ne može rebrandirati instaliranu ekstenziju kroz UI.
